# The Funniest Out-of-Office

A make.fun bounty entry: one funny out-of-office auto-reply line.

> "I'm out of office until Monday. This auto-reply is now handling all my emails — honestly, it's doing a better job than I ever did."

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Writes the single line to `/output/entry.txt`. Deterministic, no network, no randomness.
